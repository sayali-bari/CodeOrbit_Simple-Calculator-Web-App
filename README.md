Simple Calculator Web App

About the Project
This project is a simple calculator created using HTML, CSS, and JavaScript. It performs basic mathematical calculations.

Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Simple and user-friendly interface
- Store History 
- Responsive design for mobile and desktop

Technologies Used
- HTML5
- CSS3
- JavaScript

How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open the "index.html" file in your web browser.
4. Use the calculator to perform calculations.

Project Structure
- "index.html" – Contains the calculator structure.
- "style.css" – Contains the calculator design.
- "script.js" – Handles the calculator operations.

Objective
The objective of this project is to learn basic JavaScript programming and create an interactive calculator.
